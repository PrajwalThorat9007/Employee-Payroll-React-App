# Employee Payroll React App

## Project Overview

This project is a React-based Employee Payroll Application developed using a structured **Use Case (UC) approach** and **Git Flow strategy**. The application allows users to perform full CRUD operations (Create, Read, Update, Delete) on employee data using Axios and a backend (JSON Server or Spring Boot).

---

## Features

- Add Employee
- View Employee List
- Update Employee Details
- Delete Employee
- Form Validation and Event Handling
- API Integration using Axios
- Client-Server Architecture

---

## Tech Stack

Frontend:
- React.js
- JavaScript (ES6)
- HTML5 & CSS3
- SCSS

Backend:
- JSON Server (for development)
  OR
- Spring Boot (optional)

Tools:
- Git & GitHub
- Axios
